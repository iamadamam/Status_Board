# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-11-22

First public release.

### Added

- Dashboard of 187 built-in public status sources, with a status bar, counters, "Needs attention" chips and a live
  incident news ticker.
- Tiles and list views, problems first, with a resizable details panel showing incident stages and affected components.
- Vendors pane: watch or hide vendors, narrow them to products, regions or components, and arrange them into groups.
- Add any Atlassian Statuspage, status.io page or RSS/Atom feed, plus website checks, ping checks and LibreNMS alerts.
- Profiles with first-run setup; System, Light, Dark, AMOLED and Hacker themes; custom vendor logos.
- TV mode for wall screens, with pinned counters and ticker, auto-scroll and idle-hiding controls.
- Tray icon coloured by overall status and optional change notifications.
- Portable, self-contained build that writes only to its own folder.
